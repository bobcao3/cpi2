Model result streams

This proposed design keeps the agent loop in Zig. The host supplies response bytes. Sections cover state ownership, buffer lifetimes, validation, durable commits, scheduling, and cancellation.

Session redesign status. The linear frame-log draft supersedes snapshot/delta persistence and registry-revision request views as the target architecture. This page retains the earlier storage or streaming design for reference. It is not a specification of the new frame reducer.

Preserve buffer lifetimes

Worker copies input, so the host can reuse buffers after feed. Copy IDs that outlive their input buffers. Origin records request_id, generation, operation_id, and the captured capabilities_revision. Each request uses its model-intent journal sequence as generation. Frames borrow packet or decoder bytes until the next SseDecoder call or packet release. SseDecoder copies partial frames before the packet is released. ModelStream owns the Decoded JSON that Update borrows. Call ModelStream.acknowledge() only after copying or discarding the preview, never after blocked. A blocked retry consumes no input. Free packets after decoding and consuming their bytes.

ModelStream.takeResult() transfers the ID and JSON to ModelResult. When acceptResult returns staged, it has copied the result into the snapshot, freed the result, and nulled the input. A blocked result remains caller-owned. The caller frees obsolete results. Worker retains quota state until all JSON is freed. The driver releases each lease after all readers finish. EventOutbox then frees the leased bytes.

Wait for a valid final result

Send META{status, content_type} before UTF-8 DATA. content_type selects JSON or SSE. DONE carries {}, not a response body. Both modes use the same validation and retain the full output. Accept a result only after HTTP success, DONE, and a completed provider response. For SSE, the terminal event must contain that response. Never derive tool calls or history from deltas.

Follow the linked SSE rules. Reject invalid UTF-8, truncated frames, ID conflicts, and out-of-order events. Allow gaps in sequence numbers. Do not reconnect. Transport ERROR or CANCELLED fails the request even after provider completion. On a parse or quota failure, retain an owned error, abort, cancel if needed, and drain the remaining input without parsing it.

Commit before work starts

PROGRESS has sequence zero. Deltas carry the generation, item, part, channel, and UTF-8 byte offset. Merge matching keys and flush at the end of run. offer returns accepted, blocked, yielded, or obsolete. Only accepted copies data. Do not expose reasoning or append completion snapshots twice.

Reserve event slots and bytes before appending to the journal. After the fsync acknowledgment, publish without allocation or capacity failure. Staged means queued, not durable. Lua waits for the result acknowledgment. Native effects also wait for their intent acknowledgment. MODEL_RESPONSE_COMMITTED carries final public output for one generation. COMMAND_FINISHED reports the command's terminal result or error.

Schedule control before response parsing

Bound chunks, frames, queued and total bytes, JSON heap use, IDs, batches, and leases. Parsing has work limits, not time limits. Reserve each call's terminal input slot. Reserve event space for journal I/O, IO_CANCEL, and abort notices. Previews cannot use this space. Process acknowledgments and control messages before response bodies. During a journal append, accept acknowledgments, input, and lease releases, but pause other state changes. A full preview queue pauses decoding. A feed or lease release resumes WAITING work.

Before accepting a ready ModelResult, recheck its request, generation, phase, stop state, and captured registry revision. Do not send a new model request while the result waits. A tool update does not invalidate a captured revision.

Close old generations

A committed stop or stream failure emits PROGRESS{type:aborted, generation}. Discard unaccepted ModelResults, but keep known tool results. Interrupt sends IO_CANCEL. The at_boundary policy drains the transport instead. Retain the transport until its terminal reply. Commit or abort closes the generation and drops unpublished previews. Either may bypass a blocked batch. Leases remain valid, but readers ignore late previews. Reopening restores durable state, not notices or partial work.

Add WOULD_BLOCK and MODEL_RESPONSE_COMMITTED to the C bindings without changing functions or struct layouts. WOULD_BLOCK accepts no bytes and is the only retryable feed status. A permanent limit stops the producer and sends ERROR. The host preserves input order within each call but defers blocked DATA so other calls can feed. It continues draining while joining tasks. Only terminal replies retire calls.

Tests must verify progress before EOF, unchanged blocked input, and no effects before result and intent acknowledgments. They must also cover acknowledgment and cancellation with full queues and held leases, equivalent JSON and SSE results, and safe cancellation and crash recovery. Current regression coverage lives in the native contract tests and foreign ownership and crash tests. The bindings remain public. These tests do not implement the streaming proposal.
